Up to 200 guests (one row per person) and 25 tables. Each table has its own seat count, and over-full tables turn red.

Yes. Name up to three events (for example Ceremony, Reception and Welcome party) and mark who is invited to each. The dashboard counts each event.

Is the file really editable?
